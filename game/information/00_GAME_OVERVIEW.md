# Game Overview

## Title

Runtime Rush

## One-sentence description

Runtime Rush is a 2D browser skating game where the player controls momentum, jumps over obstacles, collects rewards, and uses special abilities to survive a chaotic software-themed run.

## The game in plain English

The player skates through a digital/software pipeline filled with hazards:

- bugs
- broken builds
- merge conflicts
- null errors
- unstable code blocks
- production hazards

The player must control speed, steer, jump, survive, score points, and optionally unlock short developer portfolio cards.

## Core fantasy

The player is moving fast through software chaos while barely staying in control.

The game should feel like:

```txt
I am moving fast.
I am almost losing control.
I can survive if I time things well.
Going faster gives me more score, but also increases danger.
```

## Core design pillar

```txt
Fast movement where greed creates danger.
```

This pillar should guide every design and implementation decision.

## Primary verb

```txt
Control momentum.
```

## Secondary verb

```txt
Jump.
```

## Main systems

- momentum-based skating
- steering
- jumping
- obstacles
- scoring
- combo/reward systems
- Overclock
- Focus Mode
- Patch Pulse
- optional portfolio card unlocks

## First success condition

The first target is not a huge finished game.

The first target is:

```txt
A grey-box prototype that is fun for 60 seconds.
```
