# Fun From First Principles

## What makes this game fun?

Runtime Rush should create fun through:

```txt
agency + tension + mastery + feedback + replayability
```

## Agency

The player should feel:

```txt
My choices matter.
```

Important choices:

- go faster or stay safe
- jump now or wait
- take the risky collectible or avoid it
- activate Focus Mode now or save it
- use Patch Pulse aggressively or defensively

## Tension

The main tension is:

```txt
Speed gives reward, but speed creates danger.
```

The player should constantly feel pulled between score and safety.

## Mastery

The player should get better through practice.

At first:

```txt
I can barely survive.
```

Later:

```txt
I can intentionally ride near obstacles, use Focus Mode late, and land Patch Pulse in the right place.
```

## Feedback

Every important action should produce clear feedback.

Examples:

- accelerating: longer trail, rising speed meter
- jumping: clear airborne state and landing feedback
- near miss: spark, small sound, score popup
- Overclock: stronger speed lines and multiplier display
- Focus Mode: slow motion and visual shift
- Patch Pulse: expanding landing shockwave and obstacle pop effects

## Replayability

The player should want one more run because:

- they almost survived longer
- they nearly reached a higher combo
- they misused Focus Mode
- they got greedy with Overclock
- they want to unlock the next portfolio card
- the movement itself feels good

## What fun is not

Fun is not automatically created by:

- more features
- more power-ups
- more lore
- better graphics
- higher complexity
- more UI

Those things help only if the core loop already works.
